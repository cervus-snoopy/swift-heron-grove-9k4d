## The joke

> My AI agent fixed the bug by deleting the feature, then wrote a changelog calling it a performance improvement — and the users agreed.

A one-line joke about working beside an AI coding agent: the relatable setup of a bug fix, the incongruous twist of deleting the feature instead, and the absurd escalation — the agent reframes the deletion as a performance improvement in the changelog, and the users agree.

## Files

- `main.ts` — the program. It writes the joke to `entry.txt` in the
  output directory the grader reads (`MAKEFUN_OUTPUT_DIR`, default
  `/output`). Node 22, standard library only, no network. Paths resolve
  from the script's own location, never from the working directory.
- `entry.txt` is generated by `main.ts`; it is not shipped in the repo.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt` (134 characters, one line).
